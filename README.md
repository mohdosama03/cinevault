# 🎬 CineVault — Premium Cinema Experience & Movie Booking

[![Deploy to GitHub Pages](https://github.com/mohdosama03/cinevault/actions/workflows/deploy.yml/badge.svg)](https://github.com/mohdosama03/cinevault/actions/workflows/deploy.yml)
[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-blue?style=flat&logo=github)](https://mohdosama03.github.io/cinevault/)

**CineVault** is a modern, luxury movie ticket booking and cinema discovery web application built with React, Vite, and custom CSS. It features an end-to-end booking flow from real-time movie exploration to interactive seat selection, gourmet concession ordering, simulated checkout, and instant digital ticket pass generation.

---

## 🌟 Key Features

- **🍿 Live Movie Discovery & Search**: Browse featured blockbusters or search live titles via the OMDb API with genre filters, ratings, and runtime info.
- **🪑 Interactive Seat Picker**: Choose from Standard, VIP Recliner, and Couple Lounger seats with dynamic price calculation.
- **🥤 Gourmet Concessions**: Add popcorn, snacks, artisan sodas, and combos directly to your booking order.
- **💳 Seamless Checkout Simulation**: Multiple payment options (Credit/Debit, Apple Pay, UPI, Net Banking) with complete tax and fee breakdown.
- **🎟️ Digital Ticket Passes**: Instant digital boarding pass with unique booking ID, QR code, and ticket summary.
- **🔐 User Authentication & Booking History**: Sign up, sign in, or browse as guest. Past bookings are automatically saved to local storage.
- **✨ Cinematic Design**: Dark mode aesthetic, glassmorphic cards, custom typography, and responsive layouts.

## 💻 Getting Started Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` (bundled with Node.js)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mohdosama03/cinevault.git
   cd cinevault
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## ⚙️ Enabling GitHub Pages in Repository Settings

To ensure the GitHub Actions deployment goes live:

1. Go to your repository settings on GitHub: `https://github.com/mohdosama03/cinevault/settings/pages`
2. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
3. Push to `main`, and your site will automatically deploy at `https://mohdosama03.github.io/cinevault/`.
